# 标注者本地文件说明

标注者只需认识以下文件，不需要打开或修改它们：

- `local_data/study.sqlite`：正式任务、进度和答案；
- `local_data/practice.sqlite`：与正式任务完全分离的练习进度；
- `backups/study_*.sqlite`：每次正式启动时自动生成的进度备份；
- `backups/practice_*.sqlite`：每次练习启动时自动生成的练习备份；
- 浏览器下载目录中的 `R01_annotation_results_日期.zip` 或 `R02_annotation_results_日期.zip`：唯一需要交回负责人的文件。

结果 ZIP 内含答案表、任务对应表、完成情况清单和正式数据库快照，不包含 DFEW 图片或压缩包密码。请不要解压、改名或编辑。

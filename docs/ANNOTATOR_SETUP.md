# 标注者快速清单

完整图文步骤见仓库首页的 `README.md`。开始前只需逐项确认：

- 已把 GitHub 仓库下载到电脑的 `Documents` 文件夹；
- 已把 `clip_224x224_16f.zip` 放到 `local_data/dfew/`；
- 已把负责人单独发送的个人启动包解压到仓库最外层；
- `config/project.toml`、`local_data/study.sqlite` 和 `local_data/practice.sqlite` 均存在；
- 已先启动真实图片练习，并使用 `TEST` 登录；
- 练习完成后再启动正式标注，使用个人包中指定的 `R01` 或 `R02` 登录。

看到绿色“已保存到本机”后可以关闭页面。正式任务全部达到 100% 后，在“进度”页面下载一个结果 ZIP，并将这一个 ZIP 原样发给负责人。
